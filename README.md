BMI Calculator

Консольная программа на Java: по росту и весу вычисляет индекс массы тела (ИМТ)
и определяет категорию по таблице ВОЗ. Категории и их границы хранятся в JSON
и загружаются при старте — их можно менять без перекомпиляции.

Возможности

- Расчёт ИМТ по формуле `вес / рост²`.
- Определение категории — 7 градаций: от выраженного дефицита массы до ожирения III степени.
- Категории и цвета загружаются из `BMRangefile.json` (внешний файл, не зашиты в код).
- Три реализации поиска категории: линейный, бинарный и через `Map` с диапазонами.
- Обработка ошибок: повторный ввод при некорректном значении, валидация диапазонов
  роста/веса, проверка JSON (пустой список, дубликаты, `NaN`/`∞`).

Требования

- JDK 25 (проект собран под Java 25).
- Maven 3.9+ — для сборки из исходников. Для запуска готового JAR достаточно JRE 25.

Запуск

cmd/java -jar calculator.jar
или
cmd/java -jar "calculator\out\artifacts\calculator_jar\calculator.jar"
